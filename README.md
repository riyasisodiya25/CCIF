# CCIF

> A full-stack web application built with a modern frontend and backend architecture.

## Overview

CCIF is a full-stack application developed with a modular architecture, separating the frontend and backend for better scalability, maintainability, and collaboration.

## Features

- Modern and responsive user interface
- REST API-based backend
- Modular frontend and backend architecture
- Scalable and maintainable codebase
- Designed for collaborative development

## Tech Stack

**Frontend**
- React
- JavaScript
- HTML5
- CSS3

**Backend**
- Node.js
- Express.js
